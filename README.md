# Portfólio de Dados e IA

Projetos práticos da minha trilha de estudos em dados e inteligência artificial, de 2027 a 2030. Cada semestre termina com um projeto publicado aqui.

Todos os projetos usam empresas e dados fictícios ou sintéticos. Nenhum dado real de empresa, cliente ou colega aparece neste repositório.

## A trilha

A escada é base de dados, engenharia de dados, machine learning e deep learning, e engenharia de IA. Cada projeto resolve um problema que existe em qualquer empresa, em setores diferentes, e é contado como um caso de cliente: problema, baseline, solução e resultado. Sempre que possível, uso dados públicos reais.

1. **Semestre 1 (jan a jun/2027), fundamentos:** Python, SQL, Power BI e matemática. Projeto: [painel de métricas de um negócio por assinatura](01-painel-kpis-provedor) (ProvedorX, provedor fictício: churn, SLA, NPS e tempo de atendimento).
2. **Semestre 2 (jul a dez/2027), engenharia de dados, parte 1:** Python, pipelines, dbt e Airflow. Projeto: pipeline com os dados públicos da Olist (e-commerce brasileiro), com testes e orquestração.
3. **Semestre 3 (jan a jun/2028), engenharia de dados, parte 2:** Spark, Databricks, nuvem e APIs. Projeto: lakehouse medalhão no Databricks com os dados da Olist e uma API em FastAPI.
4. **Semestre 4 (jul a dez/2028), nuvem e DevOps:** Kubernetes, Terraform e streaming. Projeto: transações de uma fintech fictícia em streaming, com detecção de anomalia em tempo real.
5. **Semestre 5 (jan a jun/2029), machine learning:** Projeto: modelo de risco de crédito com uma base pública do Kaggle, de ponta a ponta.
6. **Semestre 6 (jul a dez/2029), deep learning e MLOps:** Projeto: classificador de reclamações do consumidor.gov.br (dados abertos), com fine-tuning e MLOps.
7. **Semestre 7 (jan a jun/2030), engenharia de IA:** LLMs, RAG, agentes e avaliação. Projeto: assistente de suporte com RAG e agentes para um SaaS fictício.
8. **Semestre 8 (jul a dez/2030), IA aplicada no cliente:** Projeto final no formato de Forward Deployed Engineer, para um cliente fictício de fintech ou varejo, do escopo ao repasse.
