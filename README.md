# Portfólio de Dados e IA

Projetos práticos da minha trilha de estudos em dados e inteligência artificial, de 2027 a 2030. Cada semestre termina com um projeto publicado aqui.

Todos os projetos usam empresas e dados fictícios ou sintéticos. Nenhum dado real de empresa, cliente ou colega aparece neste repositório.

## A trilha

A escada é base de software e dados, engenharia de dados, machine learning e deep learning, e engenharia de IA. Cada projeto é contado como um caso de cliente do ProvedorX, um provedor de internet fictício, e os projetos se encadeiam: o painel vira pipeline, o pipeline alimenta o modelo e o modelo vira assistente.

1. **Semestre 1 (jan a jun/2027), fundamentos:** Python, SQL, Power BI e matemática. Projeto: [painel de KPIs de um provedor fictício](01-painel-kpis-provedor).
2. **Semestre 2 (jul a dez/2027), engenharia de software:** APIs, testes, Docker e bancos de dados. Projeto: API de dados com FastAPI, PostgreSQL, Docker e CI.
3. **Semestre 3 (jan a jun/2028), engenharia de dados:** dbt, Airflow, Spark, Databricks e nuvem. Projeto: pipeline medalhão com testes.
4. **Semestre 4 (jul a dez/2028), nuvem e DevOps:** Kubernetes, Terraform e streaming. Projeto: plataforma de dados em streaming.
5. **Semestre 5 (jan a jun/2029), machine learning:** Projeto: previsão de churn de ponta a ponta.
6. **Semestre 6 (jul a dez/2029), deep learning e MLOps:** Projeto: classificação de textos de atendimento com fine-tuning e MLOps.
7. **Semestre 7 (jan a jun/2030), engenharia de IA:** LLMs, RAG, agentes e avaliação. Projeto: assistente com RAG e agentes.
8. **Semestre 8 (jul a dez/2030), IA aplicada no cliente:** Projeto final no formato de Forward Deployed Engineer, do escopo ao repasse.
