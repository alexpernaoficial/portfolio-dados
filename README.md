# Portfólio de Dados e IA

Projetos práticos da minha trilha de estudos em dados e inteligência artificial, de 2027 a 2030. Cada semestre termina com um projeto publicado aqui.

Todos os projetos usam empresas e dados fictícios ou sintéticos. Nenhum dado real de empresa, cliente ou colega aparece neste repositório.

## A trilha

A escada é analista de dados, engenharia de dados, ciência de dados e engenharia de IA, com um curso completo por semestre.

1. **Semestre 1 (jan a jun/2027), analista de dados:** Excel, Power BI, SQL e Python. Projeto: [painel de KPIs de um provedor fictício](01-painel-kpis-provedor).
2. **Semestre 2 (jul a dez/2027), base de engenharia:** matemática, estatística, SQL, Spark e nuvem. Projeto: data lake simples em nuvem.
3. **Semestre 3 (jan a jun/2028), engenharia de dados:** dbt, Airflow e Databricks. Projeto: pipeline medalhão com testes.
4. **Semestre 4 (jul a dez/2028), engenharia de dados:** DevOps, streaming e GenAI para dados. Projeto: pipeline em nuvem com CI/CD.
5. **Semestre 5 (jan a jun/2029), ciência de dados:** machine learning. Projeto: previsão de churn de ponta a ponta.
6. **Semestre 6 (jul a dez/2029), ciência de dados:** deep learning e MLOps. Projeto: classificação de textos de atendimento.
7. **Semestre 7 (jan a jun/2030), engenharia de IA:** LLMs, RAG e agentes. Projeto: assistente com RAG e avaliação.
8. **Semestre 8 (jul a dez/2030), engenharia de IA:** IA aplicada e produção. Projeto final.
